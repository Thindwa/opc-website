# Site Announcements Sample Content

Use these examples as ready-to-paste content for the **Site Announcements** form.

## 1. Urgent circular

Best for:

- policy changes
- office circulars
- urgent internal or public notices

Suggested values:

- `Badge`: `New Circular`
- `Title`: `Office Circular: Updated Public Service Hours`
- `Message`: `Please note that public service hours have been updated effective immediately. All visitors are advised to check the revised schedule before arriving at the office.`
- `Display Mode`: `Popup`
- `Style`: `Warning`
- `Priority`: `100`
- `Primary CTA Label`: `Read Circular`
- `Primary CTA URL`: `/documents?category=circulars`
- `Open primary CTA in new tab`: `Off`
- `Secondary CTA Label`: `View Documents`
- `Secondary CTA URL`: `/documents`
- `Start At`: `Now`
- `End At`: `Optional`
- `Show on homepage`: `On`
- `Show on all pages`: `On`
- `Dismissible`: `On`
- `Show once per session`: `On`

## Recommended usage

- Use `Popup` only for the most important items.
- Use `Top Bar` for brief notices and reminders.
- Use `Slide-in` for featured content that should be visible but not disruptive.
- Keep one active high-priority record at a time.
- Add an end date for temporary notices so they expire automatically.

## Copy-ready content rules

- Keep the title short.
- Keep the message to 1 to 3 sentences.
- Use one main CTA whenever possible.
- Make the CTA match the next action you want the visitor to take.
