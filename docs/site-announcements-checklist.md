# Site Announcements Checklist

Use this checklist when creating a public announcement in the admin panel.

## Before you start

- [ ] Confirm the message is official and approved
- [ ] Choose the correct display mode
- [ ] Prepare a short title
- [ ] Prepare the main message
- [ ] Prepare 1 primary CTA
- [ ] Add an end date if the message is temporary

## Fill in the form

### Announcement Content

- [ ] `Badge`
  - Example: `Notice`, `New Circular`, `Event`, `Alert`
- [ ] `Title`
  - Keep it short and clear
- [ ] `Message`
  - Keep it to 1 to 3 sentences
- [ ] `Image`
  - Optional

### Call to Action

- [ ] `Primary CTA Label`
  - Example: `Read Circular`, `View Details`, `See Event`
- [ ] `Primary CTA URL`
  - Link to the next step
- [ ] `Open primary CTA in new tab`
  - Turn on only if needed
- [ ] `Secondary CTA Label`
  - Optional
- [ ] `Secondary CTA URL`
  - Optional

### Display Rules

- [ ] `Display Mode`
  - `Popup` for urgent alerts
  - `Top Bar` for short notices
  - `Slide-in` for featured updates
- [ ] `Style`
  - `Warning`, `Info`, `Success`, `Danger`, or `Dark`
- [ ] `Priority`
  - Higher number = show first
- [ ] `Dismiss for Hours`
  - How long before it can show again
- [ ] `Start At`
  - Optional
- [ ] `End At`
  - Optional
- [ ] `Show on homepage`
- [ ] `Show on all pages`
- [ ] `Dismissible`
- [ ] `Show once per session`
- [ ] `Active`

## Quick mode guide

### Popup

- [ ] Use for urgent or high-priority notices
- [ ] Keep message short
- [ ] Use one strong CTA

### Top Bar

- [ ] Use for compact notices
- [ ] Keep text very short
- [ ] Use one CTA

### Slide-in

- [ ] Use for featured content
- [ ] Add image if helpful
- [ ] Use a clear CTA

## Final check

- [ ] The title is readable in one line
- [ ] The message is clear and concise
- [ ] The CTA goes to the correct page
- [ ] The display mode matches the urgency
- [ ] The start/end dates are correct
- [ ] The announcement is active

## Example values

### Urgent circular

- [ ] Badge: `New Circular`
- [ ] Title: `Office Circular: Updated Public Service Hours`
- [ ] Message: `Public service hours have been updated effective immediately.`
- [ ] Mode: `Popup`
- [ ] Style: `Warning`
- [ ] CTA Label: `Read Circular`
- [ ] CTA URL: `/documents?category=circulars`

### Public notice

- [ ] Badge: `Notice`
- [ ] Title: `Scheduled Maintenance Notice`
- [ ] Message: `The website will be temporarily unavailable tonight.`
- [ ] Mode: `Top Bar`
- [ ] Style: `Info`
- [ ] CTA Label: `View Details`
- [ ] CTA URL: `/news`

### Event highlight

- [ ] Badge: `Event`
- [ ] Title: `Upcoming Official Event`
- [ ] Message: `Join us for the official event next week.`
- [ ] Mode: `Slide-in`
- [ ] Style: `Success`
- [ ] CTA Label: `See Event`
- [ ] CTA URL: `/upcoming`
